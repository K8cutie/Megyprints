## Tech Stack
- React 19 + TypeScript + Vite 7 + Tailwind CSS
- Fabric.js 5.3 (HTML5 canvas editor)
- 113 aspect-ratio page templates
- Template slot system with click-to-fill

## Current Features Working
- Album setup (size/type selection)
- 113 templates across 9 categories
- Aspect-ratio-constrained box slots (3:2, 4:3, 1:1, etc.)
- Circle/oval/rounded shape slots
- Click slot → photo picker → fills slot
- Auto-fill (shuffle photos into slots)
- Clear all slots
- Editable background (move/resize/rotate/filter)
- Snap-to-grid with alignment guides
- GitHub Pages deployment
